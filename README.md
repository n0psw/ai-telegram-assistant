# AI Telegram Assistant — Центр Красок #1

Telegram-бот для автоматических ответов на вопросы клиентов на основе базы знаний. Разработан в рамках тестового задания.

## Архитектура

- **Язык**: Python 3.11+
- **Фреймворк**: `python-telegram-bot` (асинхронный)
- **AI**: OpenAI API (`gpt-4o-mini`, `text-embedding-3-small`)
- **Поиск**: RAG (локальный векторный поиск, cosine similarity)
- **БД**: SQLite (история диалогов, статистика)
- **Деплой**: Docker / Docker Compose

## Особенности реализации

1. **RAG-система**: База знаний векторизована. При запросе бот извлекает 3 релевантных чанка и передаёт их в модель для экономии токенов.
2. **Intent Router**: Скрытый предзапрос в JSON Mode. Нерелевантные вопросы (не про краски/ремонт) блокируются до основной генерации во избежание галлюцинаций.
3. **Потоковый вывод (Streaming)**: Асинхронный генератор обновляет сообщение Telegram по мере генерации ответа.
4. **Безопасность**: Запуск в Docker под non-root пользователем, лимиты памяти, rate-limiting на стороне Telegram API.

## Запуск

1. Склонируйте репозиторий и создайте `.env`:
```env
TELEGRAM_BOT_TOKEN=token
OPENAI_API_KEY=key
OPENAI_MODEL=gpt-4o-mini
```

2. Запуск через Docker:
```bash
docker-compose up -d --build
```

3. Локальный запуск:
```bash
pip install -r requirements.txt
python bot.py
```
